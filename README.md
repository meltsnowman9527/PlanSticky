# 计划便签 (PlanSticky)

一个常驻桌面的轻量「计划便签」小窗口，把**计划管理**、**记账**、**日记**、**每日签到**
四件事装进同一个窗口：**长期计划**（无日期，一直保留）+ **短期计划**（按天管理）
+ **账本**（收支/预算/图表）+ **日记**（图文）+ **签到**（打卡/心情）。
数据全部保存在本地，启动即用、无需登录、不依赖网络。

技术栈：**Python + PySide6 (Qt6) + SQLite** —— 轻量优先（内存占用远低于 Electron），
单 exe 可打包，双击即用。界面与图表全部为 Qt 原生/自绘，**不内嵌浏览器**。

> v1.1.0 起并入原「清楚账本」的记账、日记、签到功能（原生重写）。
> 旧程序的数据库与媒体文件会在首次启动时**自动导入**（只拷贝，原目录不动），
> 且两边的数据格式保持兼容。
>
> 自动导入只找默认位置 `F:\work\money\data`。若旧程序在别处，先设环境变量
> `PLANSTICKY_MONEY_DIR` 指向它再启动一次（详见「常见问题」）。

## 快速上手（3 步）

| 情况 | 做什么 |
|---|---|
| **想直接用**（推荐） | 双击 `dist\PlanSticky.exe` —— 免安装，不需要 Python |
| **第一次从源码跑** | 双击 `setup.bat`（建 venv、装 PySide6，约 200 MB，只需一次）→ 双击 `run.bat` |
| **改了代码要看效果** | 双击 `run_debug.bat`（带控制台，能看到错误输出） |

启动后是贴在桌面上的一个小窗口；点顶栏 `✕` 是**缩到系统托盘**（不是退出），
真正退出请用托盘右键菜单里的「退出程序」。

## 功能一览

### 计划（原有）

| 功能 | 说明 |
|---|---|
| 悬浮便签窗口 | 无边框简洁外观；拖动顶栏/空白处移动，拖四边四角缩放 |
| 记忆窗口状态 | 位置、大小、是否置顶、当前 Tab、主题，重启后全部恢复 |
| 长期计划 | 无日期限制；新增 / 单击文字编辑 / ⋯删除 / 勾选完成、取消完成 / 拖动排序 |
| 短期计划 | 按日期独立管理；`← 2026年9月7日 →` 切日、`今天` 回今天、点日期弹日历选择 |
| 列表模式 | 短期页可切「多日列表」：按日期纵向列出每天计划，点日期标题跳回单日编辑 |
| 完成图 | 短期页再切「完成图」：一页一个月的月历，颜色按当天完成度分级，可前后翻月 |
| 已完成分区 | 未完成在上、已完成在下（长期计划可「隐藏已完成」） |
| 今日进度 | 顶部显示 `今日 3/7`（完成/总数）；托盘悬停提示同步显示 |
| 自动保存 | 所有改动即时写入 SQLite，无需任何“保存”按钮 |
| 深色模式 | 浅色 / 深色 / 跟随系统（跟随系统时自动响应 Windows 深浅色切换） |
| 输入体验 | Enter 保存、Esc 取消；行内编辑失焦自动保存；添加条连续回车可连录多条 |

### 记账（并入）

| 功能 | 说明 |
|---|---|
| 记一笔 | 日期、金额、支出/收入、8 类分类宫格、用途（≤40 字）、备注（≤100 字） |
| 月度概览 | 本月支出、笔数、月预算与进度条、日均支出、最高单笔 |
| 账目明细 | 表格浏览，双击或右键编辑/删除；超长文字悬停显示全文 |
| 多维筛选 | 关键词（匹配用途+备注）、分类、类型、日期范围（勾选后忽略月份） |
| 趋势图 | 近 7 / 30 / 90 天每日支出柱状图（只算支出，柱顶标注峰值） |
| 分类占比 | 当月支出环形图 + 前 5 名分类明细（金额与百分比） |
| CSV | 导入/导出（列：日期、金额、类型、分类、用途、备注；导出带 BOM，Excel 直接打开） |
| 备份恢复 | 导出/导入 JSON 备份（含预算），恢复为追加合并，不清空现有数据 |

### 日记（并入）

| 功能 | 说明 |
|---|---|
| 图文日记 | 富文本编辑（粗体/斜体/下划线），插入图片（可多选，单张≤20 MB） |
| 视频 | 插入 MP4/WebM/MOV（单个≤300 MB），点占位块弹窗播放 |
| 往日归档 | 按日期倒序列出，显示摘要与篇数，点击即打开那天 |
| 未保存提醒 | 切换日期/退出时若有未保存内容会先询问（旧版会静默丢弃） |
| 不留垃圾 | 图片/视频在**保存日记时**才落盘；未保存就自动清理临时文件 |

### 签到（并入）

| 功能 | 说明 |
|---|---|
| 签到月历 | 周一起始，已签到的日子用当天标签色标记并打勾，今天高亮 |
| 标签 | 7 个默认标签（工作/学习/运动/阅读/休息/社交/旅行）+ 自定义标签（可删） |
| 今日心情 | 最多 200 字，可与标签任选其一或同时填写 |
| 签到工具 | 记账页「工具」里可扫描并清理没有被子日记引用的孤立图片/视频 |

设计取向：界面克制、无花哨动画，长期放桌面看的工具。

## 快速开始（Windows）

### 方式 A：源码运行（需要 Python 3.10+）

1. 双击 **setup.bat**（自动建 `.venv` 并安装 PySide6，只需一次）；
2. 以后双击 **run.bat** 即可启动（无黑窗口）。

命令行等效操作：

```bat
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python main.py
```

> 提示：国内网络 pip 下载慢时，可在 setup.bat 的 pip 命令后加国内镜像参数
> （如 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）。

### 方式 B：打包成免安装 exe（推荐日常使用）

1. 先完成方式 A 的依赖安装；
2. 双击 **build_exe.bat**；
3. 产物：`dist\PlanSticky.exe` —— 单文件、双击即用，可拷到任意位置
   （数据仍在 `%APPDATA%\PlanSticky`，与源码版共用，互不冲突）。

体积约 **56 MB**（含 Qt 的 Multimedia 模块，用于日记视频播放）。

命令行等效：

```bat
pip install pyinstaller
python scripts\make_icon.py
pyinstaller --noconfirm --clean PlanSticky.spec
```

> 注意：请用 `PlanSticky.spec` 打包，不要把参数写在命令行上。
> spec 里带了 `assets/icon.ico` 数据文件和 `PySide6.QtMultimedia`
> 的 hiddenimports（视频播放是运行时 `try: import`，PyInstaller
> 静态分析看不到），命令行方式会漏掉这两个。

首次双击 exe 启动约 2~4 秒（PyInstaller 单文件解压），之后每次启动约 1 秒内。
打包后的产物可以用 `tests\exe_smoke.py` 验证（会真正启动 exe、
检查数据目录与旧数据迁移，全程用临时目录）。

## 日常使用说明

窗口顶部是 5 个 Tab：**长期 / 短期 / 记账 / 日记 / 签到**。

**计划部分**

- **切换分类**：顶部 `长期 / 短期` 分段按钮。
- **长期计划**：没有日期概念；勾掉的任务仍在列表底部，可随时取消勾选。
  想眼不见为净就打开「隐藏已完成」开关（状态会记住）。
- **短期计划**：左右箭头换天；点日期打开日历跳任意一天；`今天` 立刻回来。
- **列表模式**：「短期计划」页左上角切到「多日列表」，点任意日期标题回到单日模式。
- **完成图**：「短期计划」页切到「完成图」，看整月完成度热力分布。
- **添加**：底部「+ 添加计划」→ 输入 → 回车保存（可连续输入多条）→ Esc 收起。
- **编辑 / 排序 / 删除**：单击文字直接改；按住行尾 `⋮⋮` 拖动排序；行尾 `⋯` 删除。
- **置顶 / 最小化 / 关闭**：顶栏 📌 / `—` / `✕`（`✕` 是缩到系统托盘）。
- **换肤**：顶栏主题按钮或托盘「主题」菜单，三选一。

**记账部分**

- **记一笔**：记账页底部「＋ 记一笔」→ 填日期/金额/类型/分类/用途 → 保存账目。
- **改月份**：顶栏 `‹ 2026年9月 ›`；点中间月份文字一键回到本月。
- **编辑/删除账目**：在明细表里双击那一行，或右键选「编辑 / 删除」。
- **筛选**：搜索框匹配用途与备注；分类/类型下拉；勾「按日期范围」后按起止日期筛
  （此时忽略月份）。
- **看图表**：切到「图表」看近 7/30/90 天支出柱状图与当月分类占比。
- **改预算**：概览卡里的「月预算」输入框，改完自动保存。
- **导入导出**：切到「工具」，可导出/导入 CSV、导出/恢复 JSON 备份。
- **清理孤立媒体**：「工具」→「扫描孤立文件」可找出没有被子日记引用的图片/视频。

**日记部分**

- **选日期**：日记页顶部 `‹ ›` 换天，或「选日期」/「今天」。
- **写正文**：直接在编辑区输入；`B` `I` `U` 按钮或 Ctrl+B/I/U 加粗/斜体/下划线。
- **插图片**：「＋ 图片」可多选；**保存日记后才真正落盘**，不保存不会留垃圾文件。
- **插视频**：「＋ 视频」插入后显示为占位块，**点击即可弹窗播放**；同样保存后才落盘。
- **快捷键**：`Ctrl+B` 粗体 · `Ctrl+I` 斜体 · `Ctrl+U` 下划线。
  图片按原始宽度显示（超过 320px 会缩到 320px）。
- **保存**：点「保存日记」。切日期或退出时若有未保存内容会先问你要不要保存。
- **往日日记**：下方列表显示所有日记（日期 + 摘要），双击打开那天。

**签到部分**

- **选日期**：在月历上点任意一天（未来的日期也能提前签）。
- **选标签**：点标签胶囊选中，再点一次取消；`＋` 可新增自定义标签（右键自定义标签可删）。
- **写心情**：「今日心情」最多 200 字，可以和标签任选其一或同时填。
- **完成**：点「完成签到」；已签到的那天可点「删除签到」。

## 常见问题

**Q：桌面上看不到窗口，但托盘有小图标？**
A：窗口缩到托盘了——点托盘菜单「打开便签」或双击托盘图标。这是设计行为。

**Q：误点 ✕ 想直接退出？**
A：托盘图标 →「退出程序」。

**Q：任务很多怎么滚动？**
A：列表内鼠标滚轮即可；窗口可以拉高、拉宽，界面不会出现横向滚动条
（超长文字自动省略号，悬停显示全文）。

**Q：数据备份/迁移？**
A：复制 `%APPDATA%\PlanSticky` 整个文件夹（建议程序退出后复制）到新机器同路径即可；
也可以只复制 `plans.db`（计划）或 `ledger.db` + 两个媒体目录（账本/日记）。
用环境变量 `PLANSTICKY_DATA_DIR` 可指定数据目录（便携模式）。

**Q：原来那个「清楚账本」还能用吗？会不会冲突？**
A：两个程序可以并存，各用各的数据副本。首次启动 PlanSticky 时会把
`F:\work\money\data` 下的账本数据**拷贝**一份过来（原目录一个字节都不改），
并在 `ledger.db` 里记下 `money_imported=1` 防止重复导入。

**Q：旧数据没被自动导入 / 旧程序不在 `F:\work\money`？**
A：自动导入只认默认位置，且**导入过就不会再跑**。两种处理办法：

```bat
:: 1) 旧程序在别处：指定目录后再启动一次（在导入标记写入前有效）
set PLANSTICKY_MONEY_DIR=D:\my-money
dist\PlanSticky.exe
```

2) 已经导入过、想重新导一次：删掉 `%APPDATA%\PlanSticky\ledger.db`
   与两个媒体目录，再按上面方式启动。**注意这会丢弃融合后新记的账**，
   所以更稳的做法是先把 `ledger.db` 备份出来。

导入完成后 `%APPDATA%\PlanSticky\ledger.db` 就是主数据，不再依赖旧目录，
旧程序可以照常继续用（两边从此各自独立）。

**Q：账本数据和旧程序格式一样吗？**
A：`ledger.db` 的表结构与旧版逐列一致，日记正文也保持旧版
`div/br/img/video` 格式，所以两边可以互相打开、互换数据库文件。

**Q：想开机自启？**
A：`Win+R` → `shell:startup` → 把 `run.bat`（或 exe 的快捷方式）放进去。

**Q：卸载/清理？**
A：删除 exe/源码目录即可；如需清除数据，删除 `%APPDATA%\PlanSticky` 整个文件夹。

## 开发 / 测试

```bat
.venv\Scripts\python.exe tests\smoke_test.py          :: 计划功能（73 项）
.venv\Scripts\python.exe tests\interaction_test.py    :: 交互（17 项）
.venv\Scripts\python.exe tests\drag_drop_test.py      :: 拖拽排序（4 项）
.venv\Scripts\python.exe tests\ledger_test.py         :: 账本数据层 + 迁移（144 项）
.venv\Scripts\python.exe tests\ledger_ui_test.py      :: 记账/日记/签到 界面（138 项）
.venv\Scripts\python.exe tests\exe_smoke.py           :: 打包产物验证（需先 build）
```

前五个离屏运行（不弹窗口），共 **376 项断言**；退出码 0 = 全部通过。
`exe_smoke.py` 会真正启动 `dist\PlanSticky.exe`（含旧数据迁移与重复启动检查），
共 18 项断言。所有测试都用临时数据目录，不会触碰真实数据。

环境变量（调试用）：
- `PLANSTICKY_DATA_DIR=<目录>`   数据目录重定向
- `PLANSTICKY_LEDGER_DB=<文件>`  账本数据库单独重定向（测试隔离）
- `PLANSTICKY_SINGLE=0`          关闭单实例保护
- `PLANSTICKY_AUTOQUIT_MS=1500`  启动 1.5s 后自动退出（GUI 冒烟）
- `PLANSTICKY_MONEY_DIR=<目录>`  指定旧「清楚账本」目录（迁移用）
- `PLANSTICKY_UNSAVED_ANSWER=discard|save|cancel`  自动应答“未保存”确认框（测试用）

主要扩展点：
- 颜色与控件样式集中在 `theme.py`（两套调色板 + QSS 模板）；
- 计划的新字段改 `database.py` 的 SCHEMA；账本的新字段改 `ledger_db.py` 的 SCHEMA
  （改动时注意与旧版保持兼容）；
- 加新 Tab 参考 `main_window.py` 的 `TAB_KEYS` + 分段控件 + 页面构建；
