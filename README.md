# 计划便签 (PlanSticky)

一个常驻桌面的轻量「计划便签」小窗口：**长期计划**（无日期，一直保留）+ **短期计划**（按天管理），
数据全部保存在本地，启动即用、无需登录、不依赖网络。

技术栈：**Python + PySide6 (Qt6) + SQLite** —— 轻量优先（内存占用远低于 Electron），
单 exe 可打包，双击即用。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 悬浮便签窗口 | 无边框简洁外观；拖动顶栏/空白处移动，拖四边四角缩放 |
| 记忆窗口状态 | 位置、大小、是否置顶、当前 Tab、主题，重启后全部恢复 |
| 长期计划 | 无日期限制；新增 / 单击文字编辑 / ⋯删除 / 勾选完成、取消完成 / 拖动排序 |
| 短期计划 | 按日期独立管理；`← 2026年9月7日 →` 切日、`今天` 回今天、点日期弹日历选择 |
| 列表模式 | 短期页可切「多日列表」：按日期纵向列出每天计划（今天往前 7 天、往后 31 天，有任务的日期自动补进），点日期标题即跳回单日编辑；可滚动下拉浏览 |
| 完成图 | 短期页再切「完成图」：**一页只显示一个月**的大月历（每格带日期数字、颜色按当天完成度分级，全部完成=满格）；‹上月/下月› 前后翻月、非本月时可一键回本月；悬停看明细、点击进那天；格子随窗口宽高自适应变大 |
| 已完成分区 | 未完成在上、已完成在下（自动分开，长期计划可「隐藏已完成」） |
| 今日进度 | 顶部显示 `今日 3/7`（完成/总数）；托盘悬停提示同步显示 |
| 自动保存 | 所有改动即时写入 SQLite，无需任何“保存”按钮 |
| 系统托盘 | 点 ✕ 缩到托盘；菜单：打开便签 / 今日计划 / 置顶 / 主题 / 退出程序 |
| 深色模式 | 浅色 / 深色 / 跟随系统（跟随系统时自动响应 Windows 深浅色切换） |
| 输入体验 | Enter 保存、Esc 取消；行内编辑失焦自动保存；添加条连续回车可连录多条 |
| 数据安全 | SQLite WAL 模式 + busy_timeout；崩溃不丢数据；删任务有确认框 |

设计取向：界面克制、无花哨动画，长期放桌面看的工具。

## 目录结构

```
plan-sticky/
├── main.py                    # 入口（python main.py）
├── requirements.txt           # 唯一运行时依赖：PySide6
├── setup.bat                  # 一键：建 venv + 装依赖（首次）
├── run.bat                    # 正常启动（无控制台窗口）
├── run_debug.bat              # 带控制台启动（看日志）
├── build_exe.bat              # 一键打包单文件 exe
├── scripts/
│   └── make_icon.py           # 代码绘制应用图标 -> assets/icon.ico
├── tests/
│   └── smoke_test.py          # 离屏冒烟测试（31 项断言）
└── plansticky/                # 主包（分层清晰，便于改）
    ├── config.py              # 路径与常量（数据目录=%APPDATA%\PlanSticky）
    ├── database.py            # SQLite 数据层：任务 CRUD/排序/计数/设置
    ├── theme.py               # 浅色/深色/跟随系统（QSS + 调色板 + 注册表轮询）
    ├── icons.py               # 图标代码绘制（零图片资源）
    ├── singleinstance.py      # 单实例保护（二次启动唤起已运行窗口）
    ├── ui_common.py           # 通用控件：复选框/开关/拖拽把手/省略标签/分段Tab
    ├── task_row.py            # 单条计划行（勾选/行内编辑/⋯菜单/拖拽把手）
    ├── task_list.py           # 计划列表（完成分区 + 拖拽排序 + 空态）
    ├── add_bar.py             # 底部“添加计划”输入条
    ├── calendar_popup.py      # 日期选择弹层
    ├── main_window.py         # 主悬浮窗口（无边框缩放/几何记忆/双Tab/日期导航）
    ├── tray.py                # 系统托盘
    └── app.py                 # 组装入口 + 全局异常兜底
```

数据（自动生成，无需手动维护）：`%APPDATA%\PlanSticky\`
- `plans.db`  全部计划与设置
- `error.log` 未捕获异常记录（崩溃排查用）

## 快速开始（Windows）

### 方式 A：源码运行（需要 Python 3.10+）

1. 双击 **setup.bat**（自动建 `.venv` 并安装 PySide6，只需一次）；
2. 以后双击 **run.bat** 即可启动（无黑窗口）。

命令行等效操作：

```bat
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python main.py
```

> 提示：国内网络 pip 下载慢时，可在 setup.bat 的 pip 命令后加国内镜像参数
> （如 `-i https://pypi.tuna.tsinghua.edu.cn/simple`）。

### 方式 B：打包成免安装 exe（推荐日常使用）

1. 先完成方式 A 的依赖安装；
2. 双击 **build_exe.bat**；
3. 产物：`dist\PlanSticky.exe` —— 单文件、双击即用，可拷到任意位置
   （数据仍在 `%APPDATA%\PlanSticky`，与源码版共用，互不冲突）。

命令行等效：

```bat
pip install pyinstaller
python scripts\make_icon.py
pyinstaller --onefile --windowed --name PlanSticky --icon assets\icon.ico main.py
```

首次双击 exe 启动约 2~4 秒（PyInstaller 单文件解压），之后每次启动约 1 秒内。

## 日常使用说明

- **切换分类**：顶部 `长期计划 / 短期计划` 分段按钮。
- **长期计划**：没有日期概念；勾掉的任务仍在列表底部，可随时取消勾选。
  想眼不见为净就打开「隐藏已完成」开关（状态会记住）。
- **短期计划**：左右箭头换天；点日期打开日历跳任意一天；`今天` 立刻回来。
  每一天的计划互相独立。
- **列表模式**：「短期计划」页左上角切到「多日列表」：从上到下按日期排开，
  每天标题下显示该天计划（今天用蓝色高亮 + 「今天 ·」前缀，标题带完成计数
  `已完成/总数`）；滚动即可下拉查看前后共约 39 天的计划。点任意日期标题
  自动回到「单日」模式并打开那一天；也可以直接在列表里勾选/编辑/删除。
- **添加**：底部「+ 添加计划」→ 输入 → 回车保存（可连续输入多条）→ Esc 收起。
- **编辑**：单击任务文字直接改；回车保存、Esc 取消、点别处自动保存。
- **排序**：鼠标按住行尾的 `⋮⋮` 把手拖动，出现插入线后松手。
- **删除**：行尾 `⋯` → 删除（有确认框防误删）。
- **置顶**：顶栏 📌（或在托盘菜单勾选「置顶」），窗口始终浮在最前。
- **最小化**：顶栏 `—` 缩到任务栏。
- **关闭/隐藏**：顶栏 `✕` 是“缩到系统托盘”（程序继续运行，双击托盘图标恢复）；
  真正退出请用托盘菜单「退出程序」。
- **换肤**：顶栏主题按钮或托盘「主题」菜单，三选一；「跟随系统」约 8 秒内响应系统切换。

## 常见问题

**Q：桌面上看不到窗口，但托盘有小图标？**
A：窗口缩到托盘了——点托盘菜单「打开便签」或双击托盘图标。这是设计行为。

**Q：误点 ✕ 想直接退出？**
A：托盘图标 →「退出程序」。

**Q：任务很多怎么滚动？**
A：列表内鼠标滚轮即可；窗口可以拉高、拉宽，界面不会出现横向滚动条
（超长文字自动省略号，悬停显示全文）。

**Q：数据备份/迁移？**
A：直接复制 `%APPDATA%\PlanSticky\plans.db`（建议程序退出后复制）到新机器同路径即可。
或用环境变量 `PLANSTICKY_DATA_DIR` 指定数据目录（便携模式）。

**Q：想开机自启？**
A：`Win+R` → `shell:startup` → 把 `run.bat`（或 exe 的快捷方式）放进去。

**Q：卸载/清理？**
A：删除 exe/源码目录即可；如需清除数据，删除 `%APPDATA%\PlanSticky` 整个文件夹。

## 开发 / 测试

```bat
.venv\Scripts\python.exe tests\smoke_test.py
```

离屏运行（不弹窗口）31 项断言：数据层 CRUD/排序/隔离、主题切换、
UI 构建、添加/勾选/编辑/日期切换/隐藏已完成/重排/几何与置顶持久化。

环境变量（调试用）：
- `PLANSTICKY_DATA_DIR=<目录>`  数据目录重定向
- `PLANSTICKY_SINGLE=0`         关闭单实例保护
- `PLANSTICKY_AUTOQUIT_MS=1500` 启动 1.5s 后自动退出（GUI 冒烟）

主要扩展点：颜色与控件样式集中在 `theme.py`（两套调色板 + QSS 模板）；
新数据字段改 `database.py` 的 SCHEMA 即可；想加第三个 Tab 参考 `main_window.py` 的分段控件 + 页面构建。
