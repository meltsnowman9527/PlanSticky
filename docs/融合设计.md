# 计划便签 × 清楚账本 融合设计

把 `F:\work\money`（清楚账本）的**记账**、**日记**、**每日签到**三大功能，用 PySide6 原生控件
重写并并入 `plan-sticky`，保持"轻量单 exe、零网络、数据本地"的取向。

---

## 1. 架构决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 界面基座 | **原生 PySide6 重写**（不用 QWebEngineView） | 保持轻量（打包后 56 MB）、内存低；与现有主题体系统一 |
| 图表 | **QPainter 自绘**（`ledger_charts.py`） | 只需柱状图 + 环形图；自绘零新增依赖、深浅色自动跟随，与 `heatmap.py`/`icons.py` 风格统一（原计划用 QtCharts，实现时改为此方案） |
| 日记编辑器 | `QTextEdit` + **HTML 格式归一化层**（见 §3.3） | Qt 的 `toHtml()` 输出 `<p style=...>` 与旧版 `<div>` 不兼容，必须转换才能双向通用 |
| 数据库 | **两个库并存**：`plans.db`（原有）+ `ledger.db`（新） | 原有数据库零风险；账本表结构与 plans 完全不同 |
| 媒体文件 | `%APPDATA%\PlanSticky\journal-images` / `journal-videos` | 与 db 同目录，便携模式（`PLANSTICKY_DATA_DIR`）一并生效 |
| 主题 | 复用现有 `theme.py` 调色板 | 账本页直接吃 `color("accent")` 等，深浅色自动跟随 |
| 旧程序 | `F:\work\money` 原地保留、不改动 | 作为备份；数据为拷贝而非移动 |

**数据迁移策略**：首次运行（或用户点"导入旧数据"）时，
把 `F:\work\money\data\ledger.db` 的三张业务表 + 媒体文件**拷贝**到 PlanSticky 数据目录，
原目录一个字节都不动。导入用"表内无数据才执行"的一次性守卫，避免重复导入。

改为**两行**或**侧边竖排**导航，Tab 扩展为：

长期计划 | 短期计划 | 记账 | 日记 | 签到

- 短期页的"单日/多日列表/完成图"二级 Segmented 保持不变；
- 记账页内部二级导航：`明细 | 图表 | 预算`。

### 3.2 记账页（`plansticky/ledger_page.py`）

- **概览条**：`本月支出 ¥X` + `N 笔` + 预算进度条 + `日均 ¥X` + `最高单笔 ¥X（用途）`
  - 日均口径：当月已过天数（当月=今天是几号；非当月=该月总天数），收入单独显示在提示行
- **记一笔**（表单，可折叠）：日期（默认今天）、金额 ¥、支出/收入切换、
  分类 8 宫格（单字图标 + 名称，选中高亮）、用途（≤40）、备注（≤100）
  - 按钮：`保存账目` / `取消`；编辑已有账目时标题变 `修改这笔账`
- **明细表**：`QTableView` + 自定义 model（列：日期 / 分类 / 用途 / 备注 / 金额 / 操作）
  - 金额列：支出 `-¥x`（红）、收入 `+¥x`（绿）
  - 行内 `编辑` / `删除`（删除带确认框）
  - 筛选条：搜索框（匹配用途+备注）、分类下拉、类型下拉、起止日期
  - 日期范围优先于月份选择器（与旧逻辑一致）；空态文案 `这里还空着 / 记下第一笔支出，图表会自动生成`
- **图表页**：趋势柱状图（7/30/90 天三档，仅支出，柱顶标注 > 20% 峰值的数值，
  x 轴标签密度 7→1、30→5、90→14）+ 分类占比环形图（仅当月支出，中心显示分类个数，
  右侧列表最多 5 项：分类 / 金额 / 百分比）
- **工具**：导出 CSV、导入 CSV（列：日期,金额,类型,分类,用途,备注，带 BOM）、
  备份（导出 JSON）、恢复（从 JSON 导入）

### 3.3 日记页（`plansticky/journal_page.py`）

- 顶部：日期选择（`QDateEdit` + 前后一天箭头）
- 工具栏：`＋插入图片（可多选）`、`＋插入视频`
- 正文：`QTextEdit`（RichText），支持**段落 / 换行 / 粗体 / 斜体 / 下划线 / 图片 / 视频**
  - 图片：拷贝进 `journal-images`（UUID 命名）后以 `QTextDocument` 资源插入，随文排版
  - 视频：插入占位块（▶ + 文件名），点击用 `QMediaPlayer` + `QVideoWidget`
    在弹窗内播放（编辑器里不播视频）
- **存储格式：旧版 HTML（`div`/`br`/`img`/`video`）**，由归一化层双向转换（见下）

#### 3.3.1 日记存储与格式归一化（核心设计）

**问题**：Qt 的 `QTextEdit.toHtml()` 输出完整 HTML 文档，用 `<p style="margin...">`
而非 `<div>`，还带 `<style>` 块和 `<body style="font-family...">`。
旧版净化器只保留 `div`，因此**两者的 HTML 不可互换**：旧网页打不开 Qt 写的日记，
Qt 也不能直接 `setHtml()` 旧数据。

**方案**：自建归一化层 `plansticky/journal_html.py`，两个方向都转。

```
doc_to_old_html(QTextDocument) -> str    # 保存方向
old_html_to_doc(str) -> QTextDocument    # 打开方向（或直接 setHtml + 后处理）
```

保存方向（遍历 `QTextDocument`，**不用 `toHtml()`**）：

1. 逐 `QTextBlock` 遍历，每个非空块 → 一个 `<div>`；
2. 块内逐 `QTextFragment` 取文本并转义，按 `charFormat` 包 `<b>` / `<i>` / `<u>`；
3. 检测图片：fragment 的 `charFormat` 是 `QTextImageFormat` 时输出
   `<img src="journal-images/{uuid}.jpg" alt="...">`；若该格式带自定义属性
   `video=true`，改输出 `<video src="journal-videos/{uuid}.mp4"></video>`；
4. 空块 → `<div><br></div>`（保留空行）；
5. 输出结果**不含** `<!DOCTYPE>` / `<style>` / `<body>` / `style=` 属性，
   与旧版格式逐字节同类，旧网页可直接 `innerHTML` 打开。

打开方向：旧 HTML 用 `QTextDocument.setHtml()` 载入后，
把 `<img src="/journal-images/x.jpg">` 的 src 前缀补成文件绝对路径并注册为文档资源；
`<video>` 元素 Qt 不认，用正则先抽出，替换为带 `video=true` 属性的占位图片格式，
真实 src 存进 `QTextCharFormat` 的自定义属性，供占位块绘制与点击播放。

**兼容性收益**：旧 16 篇日记无损读入；新写的日记旧网页也能打开；
`ledger.db` 在两种程序间可自由切换。**代价**：约 250 行转换代码 + 单元测试。

#### 3.3.2 交互细节
- 归档：`往日日记` 列表（日期 + 首图缩略图或"记"字标 + 纯文本摘要 80 字），点击打开只读查看器
- 状态行：`已保存，可继续编辑` / `这一天还没有记录`；`保存日记` / `删除`

### 3.4 签到页（`plansticky/checkin_page.py`）

- 月历：周一起始，格子显示日期数字 + 签到勾；选中态/今天态高亮；上方 `‹ 2026 年 9 月 · N 天 ›`
- 编辑器：日期 + 星期、`已签到 / 今天未签到 / 未签到` 状态
  - 标签按钮行（7 个默认 + 自定义，选中描边用标签色）+ `＋` 新增标签（≤10 字，颜色轮转）
  - `今日心情` 多行输入（≤200 字）
  - `完成签到` / `删除签到`
- 与"完成图"的关系：保留两者——完成图看**计划完成度**，签到页看**生活签到**，
  两处月历可共用同一套自绘月历控件（抽到 `ui_common.MonthCalendar`）

## 4. 顺手修掉的旧版缺陷

旧版这些行为是明确的 bug（或数据安全隐患），重写时一并修正：

| # | 旧版行为 | 修正后 |
|---|---|---|
| 1 | **CSV 类型往返丢失**：导出写 `expense`/`income`，导入只认 `收入` → 收入变支出 | 导出写 `收入`/`支出`；导入同时兼容 `收入`/`expense` 与 `支出`/`expense` 旧值 |
| 2 | **失败静默**：除 3 处弹窗外，所有 API 失败无任何提示（标签重名、日记纯 `<br>` 等） | 统一错误提示条，直接展示校验失败原因 |
| 3 | **切日期丢内容**：日记/签到切换日期时静默丢弃未保存内容 | 脏标记 + 切换前确认；窗口关闭同样确认 |
| 4 | **孤立媒体**：图片/视频先上传后保存，不保存就留垃圾文件 | 保存日记时统一落盘；启动时扫描并清理无引用的媒体文件 |
| 5 | **笔数口径不一致**：`N 笔` 含收入，金额只算支出 | `N 笔` 只算支出笔数，与实际金额口径一致 |

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| Qt HTML 与旧版 HTML 不兼容 | 自建 `journal_html.py` 双向转换，不依赖 `toHtml()`/`setHtml()` 裸用；7 类内容往返一致性有测试覆盖 |
| 旧 HTML 日记里的 `<video>` 在 Qt 里无法内联 | 占位块 + 弹窗播放；存储格式保持旧版 HTML，数据无损 |
| 窄窗口塞不下账本表格 | 默认宽度 320 → 400；筛选栏两行布局、数据路径缩短显示；实测 380px 可用宽度下各页面均无横向滚动 |
| 迁移重复执行导致数据翻倍 | `settings` 写 `money_imported=1` 守卫；媒体按文件名去重（有测试） |
| 媒体文件 220 MB 拷贝耗时 | 用 SQLite 在线备份 API 保证一致性；按文件名跳过已存在文件；同步拷贝（含进度回调），实测 57 个文件秒级完成 |
| 打包漏 Qt 插件 / 数据文件 | spec 显式 `hiddenimports` + `datas`；`tests/exe_smoke.py` 真正启动 exe 验证 |
| 退出时把假崩溃写进 error.log | 数据库关闭后忽略迟到的 UI 状态写入，业务写入仍显式报错（有回归测试） |
